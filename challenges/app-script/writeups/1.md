**After connecting to challenge using ssh we can see that there is .passwd file where our file is and binary ch11 have access to it.**

**The code of that binary is provided and in that c code we can see that its using system() command and system funciton uses $PATH variable which is /bin/**

**So now if we change our path to /tmp and we make ls named binary or a bash executable without sh format and put cat inside that to read .passwd file it will solve the challenge so lets begin.**

**The challange makers were clever they blocked tmp so we can't use but there is a folder called shm in dev which stores things in memory and will be vanished after a restart. Let's use that and make a file/executable named ls and put our payload in it:**
```
#!/bin/sh  
cat /challenge/app-script/ch11/.passwd
```

**Our payload/new executable as replacement of `ls` is ready now lets change the $PATH var to `/dev/shm` using this command:**
```
export PATH=/dev/shm:$PATH
```

**After that cd to users home ~ dir and run the binary using ./ch11 or bash ch11 whatever you prefer and ls will not work now in current tty cuz our custom one is there and it will run.**
