## Challenge name: FTP - authentication

``` Challenge Link:``` [https://www.root-me.org/en/Challenges/Network/FTP-authentication](https://www.root-me.org/en/Challenges/Network/FTP-authentication)

**We have to download the .pcap file given to start the challenge that is a file type which stores network traffic packets and the objective is straightforward: inspect the captured traffics and extract the password used by the user during FTP authentication.**

**So, we have downloaded the .pcap file and to analyze it we have to use tools like wireshark or tshark.**

```
tshark -r ch1.pcap
```

**After running it we can see that it throws a bunch of texts which are mixed with different kind of protocol requests captured since we know that we are finding ftp authentication details and it doesn't encode passwords so we can pipe output to grep to make our life easier and get the hardcoded creds using:**

```
tshark -r ch1.pcap | grep FTP
```

**We can observe that one had used cdts3500 as user & pass to login using ftp.**

**So, we can use this "cdts3500" as flag/passwd to validate the challenge..**
