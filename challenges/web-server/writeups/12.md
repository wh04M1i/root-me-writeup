## Challenge name: CRLF

``` Challenge Link:``` [https://www.root-me.org/en/Challenges/Web-Server/CRLF](https://www.root-me.org/en/Challenges/Web-Server/CRLF)

**The description says that we have to inject false data in the journalisation log.**

**CRLF stands for Carriage Return Line Feed. In HTTP requests `\r\n` breaks the line. URL encode that as %0d%0a.**

**Our payload: `?username=admin%20authenticated.%0D%0Aguest&password=don't+care`**

**We are able to put our arbitrary text in the server log using CRLF injection. We can use this "rFSP&G0p&5uAg1%" as flag/passwd.**
