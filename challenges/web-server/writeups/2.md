## Challenge name: HTTP - Open redirect

``` Challenge Link:``` [https://www.root-me.org/en/Challenges/Web-Server/HTTP-Open-redirect](https://www.root-me.org/en/Challenges/Web-Server/HTTP-Open-redirect)

**After starting the challenge we land on page which lists some socials like facebook, twitter and so on..**

**If we click on one of them it will redirect us to their respective sites. But before redirection take a look at the link. We can see its redirecting us to facebook.com as we clicked on facebook and also has some kind of verification going on using a hash in &h=<hash> parameter.**

**I took the hash and pasted it on hash type identifier - it found out that it's a md5 hash. So to do open redirect we need to redirect user to another domain rather than the given one. We have to compute its md5 hash put it in the hash parameter so server checks md5 hash of the url and passes the verification.**

**After that we will craft our payload as: `http://challenge01.root-me.org/web-serveur/ch52/?url=https://evil.com&h=7a1eb5272a0de83226e7a50d14334056`**

**When we use this payload we are being redirected to evil.com and before redirection it prints the flag/password to solve the challenge.**
