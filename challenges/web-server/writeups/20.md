## Challenge name: PHP - Serialization

``` Challenge Link:``` [https://www.root-me.org/en/Challenges/Web-Server/PHP-Serialization](https://www.root-me.org/en/Challenges/Web-Server/PHP-Serialization)

**After starting the challenge, we are presented with a login page. We can log in as `guest`, but this account has restricted access.**

**Looking at the source code, we notice the presence of an `autologin` cookie. User-controlled cookie data is passed directly to `unserialize()`, which is dangerous.**

**The comparison uses PHP's loose comparison operator `==` instead of `===`. Type juggling allows us to bypass authentication.**

**We craft a serialized array with login `superadmin` and password boolean `True`:**

```php
$data = array('login' => 'superadmin', 'password' => True);
echo serialize($data);
// a:2:{s:5:"login";s:10:"superadmin";s:8:"password";b:1;}
```

**Replace the autologin cookie with this URL-encoded payload and refresh the page.**
