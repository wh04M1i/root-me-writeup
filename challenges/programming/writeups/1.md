## Challenge name: TCP - Back to school

``` Challenge Link:``` [https://www.root-me.org/en/Challenges/Programming/TCP-Back-to-school](https://www.root-me.org/en/Challenges/Programming/TCP-Back-to-school)

**The challenge is to create a TCP connection to the server, do some computation and send the result back to the server.**

**Let's code in python to solve this and our solver looks like this:**

```python
import socket
 
host = "challenge01.root-me.org"
port = 52002
 
s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
s.connect((host, port))
 
data = s.recv(1024)
 
# Extract the numbers from the string
number1 = data.decode().split("Calculate the square root of ")[1].split(" and multiply by ")[0]
number2 = data.decode().split(" and multiply by ")[1].split(" =")[0]
 
# Calculate the result
result = str(round(int(number1)**0.5 * int(number2), 2))+'\n'
 
# Send the result back to the server
s.sendall(result.encode())

# Get the response from the server
data = s.recv(1024)
print(data.decode())
```
