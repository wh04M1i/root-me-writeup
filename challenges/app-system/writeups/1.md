**In the code buffer defined to take user input was `char buf[40];` but input is read using `fgets(buf, 45, stdin)` which can read up to 44 bytes plus a null terminator. If more than 40 bytes are read, memory past `buf` will be overwritten and this allows us to overwrite adjacent stack variables.**

**We can provide 40 plus bytes of junk and pass that first if conditional check because after 40+ bytes the check will be overwritten and will not be deadbeef and now to reach inside the second if condition which holds main stuff in this challenge we need to make the value of check equal to 0xdeadbeef. On x86 (little-endian), to set check = 0xdeadbeef, we need to write it in little-endian order as `ef be ad de`.**

```
Payload:

```
